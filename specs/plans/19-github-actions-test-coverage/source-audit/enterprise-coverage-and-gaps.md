HEAD `f0b17b7` has **61 files**: the same filenames plus `common-logging`, `logging-collector`, and `logging-packaging` integration files. It also changes assertions in existing files. `OCC_TEST_LOGGING_COLLECTOR=1` selects two real Collector/Docker cases; the Kubernetes-processor case uses synthetic OTLP metadata with the `k8sattributes` processor removed, so it is not live-cluster identity proof. ## Gaps CI configuration alone cannot fix

1. **Exit zero is insufficient.** Image, Helm, DB, cluster and credential gates can skip cases. The harness ordinary, routing and Slack selections have different expected sets. Record file ownership plus expected named cases and narrow counterpart skips; running every file does not establish every selected scenario passed.
2. **Fresh-state DBs are required.** Auth-account and platform-state proofs dynamically skip an already-bootstrapped Installation. Use a fresh migrated DB per file/fresh-state retry. Run the six worker DB cases explicitly. The failure suite requires loopback `openclaw_failures_*` under `OCC_BOOTSTRAP_FAILURE_DATABASE_URL` and matching migration URL; production wireup requires separate empty `OCC_PRODUCTION_WIREUP_DATABASE_URL`. [Auth skip](https://github.com/openclaw/openclaw-enterprise/blob/1233e13aa6e1a2e4f502fa5febf06f5531c19f2c/tests/integration/postgres-auth-accounts.test.mjs#L94-L100), [platform skip](https://github.com/openclaw/openclaw-enterprise/blob/1233e13aa6e1a2e4f502fa5febf06f5531c19f2c/tests/integration/postgres-platform-state.test.mjs#L230-L243), [failure admission](https://github.com/openclaw/openclaw-enterprise/blob/1233e13aa6e1a2e4f502fa5febf06f5531c19f2c/tests/integration/postgres-bootstrap-failures.test.mjs#L17-L112).
3. **Four live-Configuration cases still need repair.** `OCC_TEST_KUBERNETES_CONFIGURATION=1` selects platform-state cases at lines 318, 537, 1123 and 1410. For example, Agent creation supplies only `name`, while the current contract requires `configurationId`; other payload/Driver setup assumptions need the same current-contract audit. This is a confirmed source mismatch, not an observed test failure in this task. Repair realistic Configuration resources, startup and outcomes without relaxing API validation or substituting mocks. [Mismatch](https://github.com/openclaw/openclaw-enterprise/blob/1233e13aa6e1a2e4f502fa5febf06f5531c19f2c/tests/integration/postgres-platform-state.test.mjs#L318-L354), [contract](https://github.com/openclaw/openclaw-enterprise/blob/1233e13aa6e1a2e4f502fa5febf06f5531c19f2c/packages/contracts/src/api/common.ts#L226-L246).
4. **Environment leakage selects other suites.** OpenShell treats shared DB/image/kube variables as selection and then requires its explicit flag. Supply inputs only to exact-file subprocesses, never to an integration glob. [Selector](https://github.com/openclaw/openclaw-enterprise/blob/1233e13aa6e1a2e4f502fa5febf06f5531c19f2c/tests/integration/sandbox-driver-openshell-k3d-real.test.mjs#L24-L65).
5. **Image and cluster preparation are separate contracts.** Controller builds require `--target runtime --build-arg NODE_BASE_IMAGE=<approved-node24-digest>`; the prior report's stale `production`-target documentation finding is retired because current testing docs link to the deployment prerequisites. Runtime pins remain OpenClaw 2026.7.1, Codex plugin 2026.7.1-1, Slack plugin 2026.7.1 and Codex 0.147.0; Node must be 24.15+. Do not upgrade these merely to copy upstream CI. k3d imports local tags and must register the exact digest refs requested by Pods. [Controller Dockerfile](https://github.com/openclaw/openclaw-enterprise/blob/1233e13aa6e1a2e4f502fa5febf06f5531c19f2c/Dockerfile), [runtime Dockerfile](https://github.com/openclaw/openclaw-enterprise/blob/1233e13aa6e1a2e4f502fa5febf06f5531c19f2c/deploy/runtime/Dockerfile), [current image instructions](https://github.com/openclaw/openclaw-enterprise/blob/1233e13aa6e1a2e4f502fa5febf06f5531c19f2c/docs/testing.md#L239-L250).
6. **Routing and OpenShell need readiness proof.** Envoy coverage requires actual Gateway API/Envoy/cert-manager CRDs/controllers, Helm and a disposable CA cert/key passed through `OCC_TEST_GATEWAY_CA_CERT_PATH` and `OCC_TEST_GATEWAY_CA_KEY_PATH` (trust also supports `NODE_EXTRA_CA_CERTS`). Its helper checks existing controllers; it does not install them. OpenShell's RuntimeClass/controller portability on hosted Docker/k3d remains unproved. [Envoy readiness](https://github.com/openclaw/openclaw-enterprise/blob/1233e13aa6e1a2e4f502fa5febf06f5531c19f2c/tests/helpers/envoy-workspace-gateway.mjs#L121-L153), [CA inputs](https://github.com/openclaw/openclaw-enterprise/blob/1233e13aa6e1a2e4f502fa5febf06f5531c19f2c/tests/helpers/envoy-workspace-gateway.mjs#L359-L373).
7. **External side effects need dedicated resources.** Slack requires `SLACK_APP_TOKEN`, `SLACK_BOT_TOKEN`, distinct `OCC_TEST_SLACK_SENDER_BOT_TOKEN`, test channel and literal-IP proxy with port. Provider coverage needs an authorized test ChatGPT workspace/admin key. Model tests spend credits. Approve scope, spend, cleanup and an owner before running them. [Slack contract](https://github.com/openclaw/openclaw-enterprise/blob/1233e13aa6e1a2e4f502fa5febf06f5531c19f2c/tests/integration/harness-topology-k3d-real.test.mjs#L3826-L3867), [provider prerequisites](https://github.com/openclaw/openclaw-enterprise/blob/1233e13aa6e1a2e4f502fa5febf06f5531c19f2c/tests/integration/service-account-driver-real.test.mjs#L53-L71).
