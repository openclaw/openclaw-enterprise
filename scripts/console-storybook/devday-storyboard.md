# DevDay Console demo storyboard

This storyboard covers two connected Storybook segments for the OpenClaw
Enterprise (OCE) Console. The stories use production Console modules with a
simulated API fixture. The Admin UI is a schematic chat fixture, not the bundled OpenClaw Control UI.
They do not store real credentials, deploy workloads,
prove repository grants, prove Slack delivery, or contact a native gateway.

## Segment 1: create `devday claw`

Storybook story: `Flows / DevDay segment 1: create devday claw`.

| Scene                       | Presenter action                                                                                                                                                                                                                      | Expected visible state                                                                                                                                                    | Fallback                                                                                                                                              |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Start from Agents           | Open the story. The list includes the already deployed `oceclaw` seed. Click **Create Agent**.                                                                                                                                        | The real Create Agent entry point opens from the Console list.                                                                                                            | Use **Reset story**. If the list is already past this point, reset before recording.                                                                  |
| Select the Codex Preset     | Select the Codex Preset. Enter `devday claw` for the Preset variable, then choose **Use Preset**.                                                                                                                                     | The real Create Agent form opens with OpenAI, Codex, Dedicated execution, editable Configuration JSON, Repository access, Channels, Secret bindings, and workspace files. | If Presets do not load, use **Start without Preset** and enter the same Agent name.                                                                   |
| Enter fake model credential | Enter `sk-demo-devday-codex-api-key` in **API key** and select `gpt-6-astra`.                                                                                                                                                         | The API key stays masked. Model selection updates Configuration JSON with `codex/gpt-6-astra`.                                                                            | Use **Enter model ID manually** and type `gpt-6-astra`.                                                                                               |
| Select repository           | Select `openclaw/openclaw-enterprise`, then choose Contributor access.                                                                                                                                                                | Repository access shows the selected repository and write-limit notice.                                                                                                   | Continue without repository access only if repository discovery is intentionally unavailable, and call out that the repository step is unverified.    |
| Configure channels          | Open **Configure Slack**. Enter `COPENCLAW, COPENCLAWFEEDBACK`, representing `#openclaw` and `#openclaw-feedback`. Select the pre-existing simulated `devday claw` Slack app and bot Secrets, then choose **Apply channel settings**. | Configuration JSON contains Slack Socket Mode settings. Secret bindings JSON references the simulated Namespace Secrets and never exposes token values.                   | If the drawer is still loading Secrets, wait for the Secret menus. If a Secret is unavailable, choose **Reset story**.                                |
| Create and deploy           | Choose **Create Agent** and wait. Use **← Agents** after Workspace files open, then continue to segment 2.                                                                                                                            | The Console shows provisioning submission, provisioning progress, deployment activation, then opens Workspace files for the admitted revision.                            | If the status is mid-progress during recording, keep the frame visible until Workspace files open. If the fixture reports an error, reset and replay. |

## Segment 2: open `oceclaw` Admin UI

Storybook story: `Flows / DevDay segment 2: oceclaw Admin UI`.

| Scene               | Presenter action                             | Expected visible state                                                                                                                                       | Fallback                                                                                      |
| ------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| Open deployed Agent | Start on the Agents list and open `oceclaw`. | Agent detail shows a selected deployed revision, simulated deployment status, and Native admin UI access. The Slack fixture represents `#openclaw-feedback`. | If the link has already opened, use **Reset story** to return to the list.                    |
| Launch Admin UI     | Click **Open native admin UI**.              | A new fixture page opens for `oceclaw` with an existing message in `#openclaw-feedback`. The page is labeled as simulated.                                   | If popups are blocked, copy the link from the button and open it in the same browser session. |
| Add a message       | Enter a new message and click **Send**.      | The transcript shows the new message and a visible simulated `oceclaw` result.                                                                               | If the message was blank, enter nonempty text and submit again.                               |
