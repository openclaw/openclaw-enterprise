# DevDay Console demo storyboard

This storyboard covers two connected Storybook segments for the OpenClaw
Enterprise (OCE) Console. The stories use production Console modules with a
simulated API fixture. The Admin UI is a schematic chat fixture, not the bundled OpenClaw Control UI.
They do not store real credentials, deploy workloads,
prove repository grants, prove Slack delivery, or contact a native gateway.

The **devday** Preset is loaded from `deploy/presets/devday.json`, a copy of the
standard Codex Preset with Slack prefilled. Installation file loading is described
in the [Preset reference](../../docs/reference/presets.md#installation-defaults).
Segment 1 offers SWE Agent, Community Agent, Q&A Agent, and Oncall Agent,
alongside both standard presets. The walkthrough below uses SWE Agent.

The DevDay plugin picker reuses the 26 curated connector names and IDs from
the static suggestions catalog, including Linear, GitHub, Slack, Notion, and
Figma, plus the Calendar demo fixture. All appear on the first page. Linear
has simulated search and create issue tools; the other curated entries
provide plugin defaults without a simulated tool inventory. These fixtures do
not establish live availability or connection status. The checkpoint also adds
Linear with an automatic default reviewer and asks for approval to create issues.

The preset includes the supplied `AGENTS.md` template, with its draft decisions preserved.
The heading and all self-references use `{{vars.name}}`; entering `devday claw`
produces `# devday claw` and `You are devday claw` when applying any DevDay preset.
