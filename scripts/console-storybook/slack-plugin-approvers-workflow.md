# Slack plugin approvers

These stories use production Console controls with simulated Agent, Secret, and directory responses. They do not prove runtime approval enforcement.

1. Open **Pages / Create Agent / Plugin approvers need a Slack bot Secret**. Choose a bot Secret beside the people field, or enter an exact ID. Open **Search for plugin approvers** to select a name from the simulated directory. The search-only Secret does not configure the Slack channel.
2. Open **Pages / Agent detail / Plugin approver inheritance** and **Plugin and tool approver overrides**. Expand Calendar and Create event. Confirm the Agent default, plugin inheritance or empty override, and tool override are distinct. Change a mode, then inspect Plugin selections JSON before saving. These two stories enable plugin and tool approvers on the Codex fixture catalog; the real Codex Plugin Driver offers only the Agent default, and other Codex stories hide those fields.
3. Open **Pages / Agent detail / No Slack approvers hints**. Calendar starts on **No Slack approvers** with an empty list: the hint is `No Slack user can approve.` and the people picker is hidden. Change the mode to **Selected Slack users** without adding anyone: the hint becomes `No Slack user can approve until people are selected.` and the picker is shown. Change it back to **No Slack approvers**: the first sentence returns and the picker hides.
4. Open **Pages / Agent detail / Preserved non-Slack approver**. Calendar starts on **No Slack approvers** with one simulated non-Slack entry: the hint is `No Slack user can approve. 1 other channel entries are preserved.` and the people picker is hidden. Change the mode to **Selected Slack users**: the picker is shown and the hint stays `0 Slack approvers selected. 1 other channel entries are preserved.` because that entry remains. Change it back to **No Slack approvers**: the preserved-entry sentence returns and the picker hides. The `teams` / `person-1` entry is fixture data, not a real channel.
5. Open **Pages / Agent detail / Find Slack plugin approvers**. The open Alex search distinguishes people with the same display name by their handles. Switch to another browser tab and return; the query and results stay open while access is checked. Move focus to another Console control to close the list, then focus the field to search again. Selecting Alex Chen immediately shows their name and handle in the chip. The saved policy uses the workspace-qualified selector. Entering a selector from another workspace after lookup shows an error. Check that the results dropdown remains usable near the bottom of a scrollable plugin or tool editor.
6. Open **Pages / Agent detail / Plugin approvers accept raw Slack IDs**. The simulated API returns 501 for channel directory lookup. Confirm the picker explains that exact IDs remain available, add `UDEMO123`, and save plugin selections. The saved draft keeps the raw Slack user ID and the chip says **Name unavailable**. The selection can still be removed.

See [Slack directory](slack-directory-workflow.md) for channel and user name lookup stories.
