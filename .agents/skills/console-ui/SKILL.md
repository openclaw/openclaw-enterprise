# Change the Console UI

Start with the [Console components and styles](../../../docs/contributing/console-ui.md).
Find the closest production page and its Storybook story before adding a component.
Change a shared pattern at its source and inspect it on the pages that use it.
Keep permissions, request outcomes, and recovery in the feature that owns them.

Follow the repository's [visual review requirements](../../../AGENTS.md#console-storybook)
and [local development workflow](../local-dev/SKILL.md).
