# Documentation inventory

For the September 29, 2026 clarity review, see the
[documentation quality audit](documentation-inventory/quality-audit-2026-09-29.md).
It records 14 findings and their resolution in PR #615. The inventory below
retains the earlier audit and its proposals.

This audit mapped the documentation to **Getting Started**, **Topics**, **Integrations**, **Reference**, and **Contribute**. It assigns a destination, action, and quality rating to **224 tracked Markdown files**: 121 website pages and 103 repository-only files. This audit predates the website reorganization and records what the source looked like at the time.

The tables below preserve the earlier five-menu proposal, including suggestions that were not adopted. The site now has six sections: **Getting Started**, **Topics**, **Integrations**, **Operate**, **Reference**, and **Contribute**. Getting Started offers local Kubernetes setup and a first Agent; joining an existing installation and the Docker/Podman preview are deferred. Use the [documentation home](README.md) for the current layout and the [organization and naming guidance](../.agents/skills/technical-writing/references/documentation-navigation.md) when changing it. Pinned evidence below refers to the original source snapshot.

The snapshot is the [documentation PR #258](https://github.com/openclaw/openclaw-enterprise/pull/258) at [6b345824](https://github.com/openclaw/openclaw-enterprise/commit/6b34582433df1ad29f320b1c129a0d601e40fa3f), compared with [main at 5f7728e](https://github.com/openclaw/openclaw-enterprise/commit/5f7728e8c5d128bc7067b7035e07f06c3c4da92c). Of the 224, 209 were unchanged from main, 11 were updated in that PR, and four existed only in the PR: the [product guide](guides/README.md), [first-Agent guide](guides/first-agent.md), [contributor guide](contributing/README.md), and [first-change guide](contributing/first-change.md). The new audit pages are not in that count. YAML, source code, workflows, and CLI implementation were checked as supporting evidence when needed, but are not Markdown inventory entries. No product behavior was run for this audit.

## Fix accuracy before moving pages

1. **Explain where a deployment can run.** The [architecture](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/docs/ARCHITECTURE.md#L170-L179) and [controller reference](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/docs/reference/controller.md#L126-L136) imply the default Docker/Podman profile deploys Agents; the [Docker implementation rejects required Harness authentication](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/apps/controller/src/drivers/compute/docker/index.ts#L340-L348). The [Docker reference](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/docs/reference/drivers/docker-compute.md#L9-L15) also wrongly presents Kubernetes as the only option; [SSH supports embedded runtime-managed authentication](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/apps/controller/src/drivers/compute/ssh/index.ts#L368-L378).
2. **Stop promising a working first model response on trusted-proxy installations.** The [first-Agent guide](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/docs/guides/first-agent.md#L89-L99) sends readers to an operator procedure whose [TUI verification requires token authentication](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/docs/guides/deploy/production-agents.md#L218-L231); [private workspace routing requires trusted-proxy mode](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/docs/guides/deploy/workspace-routing.md#L114-L142). Document a verified supported path or disclose that model-response verification is unavailable in this mode. File access is not model-response proof.
3. **Correct the promise about failed replacement.** The [reconciliation reference](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/docs/reference/controller/reconciliation.md#L165-L180) promises that a failed replacement preserves the predecessor. The [Harness reference](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/docs/reference/harness-execution.md#L98-L114) and [Kubernetes implementation](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/apps/controller/src/drivers/compute/kubernetes/index.ts#L1703-L1711) show that embedded replacement can stop the working gateway before validating the replacement credential.
4. **Correct security and integration guidance.** The [authorization reference](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/docs/reference/authorization.md#L93-L105) omits permissions defined by [native IAM](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/packages/iam/src/index.ts#L108-L132). The [OpenShell page](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/docs/reference/drivers/openshell-sandbox.md#L176-L201) buries stock-version identity and secret-delivery blockers. The [console reference](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/docs/reference/console.md#L51-L60) describes an Agent-owned plugin picker that the [current form does not provide](https://github.com/openclaw/openclaw-enterprise/blob/6b34582433df1ad29f320b1c129a0d601e40fa3f/apps/controller/src/console/agents/create.mjs#L152-L170).

## Actions and quality

The recommendations are **76 keep**, **55 rewrite**, **16 split**, **nine merge**, and **68 archive**; none needs outright deletion. Archive means retain in repository history or remove from primary navigation, not erase the file. Archived drafts remain drafts; shipping or approval cannot be inferred from their location. For merges, carry over unique useful material and preserve old links; for splits, the inventory names the new owners.

Quality is separate from action: **Good** (60), **Adequate** (73), **Weak** (18), **Historical** (70), and **Generated** (3). Weak means substantive accuracy or usability issues, not just copyediting. Historical sources are evaluated as records, not as current promises. Generated pages can still need changes through their owner.

The [missing pages and ownership gaps](documentation-inventory/gaps.md) record other findings from this snapshot. Check the current documentation and source before treating an item as still open. Update the site navigation and [repository instructions](../AGENTS.md) together when changing ownership; the site's access restrictions remain unchanged.
