# Explore the HTTP API

Find an operation, check its permissions, and copy a complete request or response
example. For a text-only view, use the [Markdown reference](api.md), which is also
available in site search. Both views use the same generated OpenAPI contract.

Examples contain synthetic IDs and credentials. Replace them with your own values.
**Test Request affects the selected server**, initially `http://127.0.0.1:3000`.
Credentials are not saved or sent through a third-party proxy. If the browser
blocks a cross-origin request, use the curl example; keep OCC's origin checks enabled.

Start with the [HTTP quickstart](../guides/http-api.md), or follow
[create and deploy an Agent](../guides/http-api-agent.md). Session-only operations
require human sign-in; OAuth examples need a real browser-bound attempt.
